# Attribution

This repository contains an evidence-led rewrite of Conceal Network documentation. It does not import the legacy DokuWiki as a byte-for-byte copy.

Where migration material is substantially adapted from a legacy page, the relevant page identifies that legacy URL and the material is attributed to the [Conceal Network legacy wiki](https://conceal.network/wiki/), which states the GNU Free Documentation License 1.3 in its footer. New prose is derived from the first-party sources linked on each documentation page.

The legacy wiki remains authoritative until a separately approved cutover. This repository does not alter its FTP hosting, DNS, or production deployment.
