# Brand assets

Official Conceal imagery used by the site shell. Documentation walkthrough
screenshots live in `public/screenshots/` with their own provenance notes.

- `conceal-mark.svg` — the official mark ("Logo svg file") from
  <https://conceal.network/branding>. Silvery greyscale ramp; used on dark
  backgrounds.
- `conceal-mark-on-light.svg` — light-background variant derived from the
  official vector by remapping the greyscale ramp onto the Conceal Wallet
  warm-charcoal palette.
- `desktop-wallet-dashboard.png` — the official Desktop Wallet 6.7.8
  dashboard capture published on <https://conceal.network/> (sourced from
  `/images/newgui678.png` on 6 September 2026). Used as the homepage hero.
  It is the project's own published product shot; if the main site replaces
  it with a newer capture, update this file and the homepage.
