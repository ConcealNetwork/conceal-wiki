CCX is the native asset of the Conceal network. Core defines the network rules and issuance. The explorer reports current chain data.

## Fixed consensus issuance

Core sets a maximum supply of **200,000,000 CCX**, six decimal places, and a **120-second** block target. After the consensus-v8 activation height, the base reward is **6 CCX** per block and cannot exceed the remaining supply. Transaction fees and deposits do not change that base reward calculation.

These are fixed consensus parameters in the referenced Core source, not a statement of how much CCX has already been issued. The release and source actually run by network participants determine the rules they enforce.
