CCX is the native asset of the Conceal network. Network rules and issuance are implementation details that should be read from the current Core source and checked against live network information, not copied from an old static table.

## Network information

Use the [Conceal block explorer](https://explorer.conceal.network/) for current chain and pool-directory information. Treat it as a live service: its displayed state can change after this page's verification date.

The Core repository's [consensus configuration](https://github.com/ConcealNetwork/conceal-core/blob/master/src/CryptoNoteConfig.h) is the source for implementation-level network parameters. Pair it with the [Core releases page](https://github.com/ConcealNetwork/conceal-core/releases) when evaluating a version or upgrade.

## What this page does not claim

This page does not promise liquidity, profitability, exchange availability, or a particular network service level. Those are volatile conditions that need their own current, independent assessment.
