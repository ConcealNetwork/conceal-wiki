CCX is the native asset of the Conceal network. Network rules and issuance are implementation details that should be read from the current Core source and checked against live network information, not copied from an old static table.

## Fixed consensus issuance

The current Core source configures a maximum money supply of **200,000,000 CCX**, six decimal places, and a **120-second** target between blocks. After the consensus-v8 activation height, the base reward function uses **6 CCX** per block and caps each reward at the supply remaining. Transaction fees and deposit state are separate from that base issuance calculation.

These are fixed consensus parameters in the referenced Core source, not a statement of how much CCX has already been issued. The release and source actually run by network participants determine the rules they enforce.

## Live issued supply

At the **2026-09-05 04:54:15 AEST** live explorer snapshot, block 2,152,231 reported **33,712,033.757459 CCX** already generated and **11,436,394.196725 CCX** in deposits. The explorer derived **22,275,639.560734 CCX** circulating by subtracting those deposits from generated coins, and reported a 6 CCX base reward for that block.

Those height, issued-supply, deposit, and circulating values are time-sensitive explorer state. Use the [Conceal block explorer](https://explorer.conceal.network/) for a current view instead of treating this dated snapshot as live now.
