Choose a wallet whose recovery and verification process you understand before you receive funds. Only download from the project-controlled release pages, and preserve a verified backup before changing devices or software.

## Wallet options

- **Desktop wallet:** suited to people who want a full desktop application. Review [Desktop releases](https://github.com/ConcealNetwork/conceal-desktop/releases) for the dated current release snapshot and its published assets.
- **Core CLI:** suited to operators and advanced users who are comfortable with the Core tools. Start from [Core releases](https://github.com/ConcealNetwork/conceal-core/releases).
- **Web Wallet:** browser-based access with its own local-browser and device risks. Use the [official Web Wallet releases](https://github.com/ConcealNetwork/conceal-web-wallet/releases), not a link from an untrusted message.
- **Android wallet:** use the [official Android release page](https://github.com/ConcealNetwork/conceal-wallet-cordova/releases) to identify the current supported package and verification information.

Dedicated pages will cover installation, recovery, and verification for each option. Next Wallet is documented separately as experimental and is not presented as a production replacement.

## Before receiving CCX

1. Confirm you are on the intended official release page.
2. Verify the available integrity information for the file you selected.
3. Complete the wallet's backup process and keep the backup private and offline.
4. Make a small, reversible test of the address and workflow before relying on it.

Never share recovery material, wallet passwords, or private keys with a person or website claiming to provide support.
