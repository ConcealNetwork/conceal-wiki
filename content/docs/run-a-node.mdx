Run a Conceal node on a host where you control storage, network access, and updates. This guide covers **Core 6.7.5** and **Guardian 0.7.8**. Check both release pages before installation.

## Core installation

1. Start at the official [Core releases page](https://github.com/ConcealNetwork/conceal-core/releases), select the intended release and platform asset, and read its notes.
2. Verify a published checksum or signature before running an asset. If the release does not provide integrity information you can independently validate, stop and assess that risk before proceeding.
3. Follow the [Core build and operating documentation](https://github.com/ConcealNetwork/conceal-core/tree/master/docs) for the exact release and platform. Preserve a backup of any local data before changing versions or storage paths.
4. Check synchronization and network state through the [live Conceal explorer](https://explorer.conceal.network/) as an independent, time-sensitive reference.

## RPC and host boundaries

Treat daemon and wallet RPC as private administration interfaces. Never publish an unauthenticated RPC endpoint. If a remote application needs access, add authentication, network filtering, encryption, logs, and a way to revoke access. Check the Core documentation for your installed version before exposing the endpoint.

Run services with the fewest host permissions they need. Separate administrative access from public services. Keep the operating system and node software patched, then check disk use, logs, and restart behaviour after upgrades.

## Guardian monitoring

[Conceal Guardian](https://github.com/ConcealNetwork/conceal-guardian) monitors the `conceald` daemon. This guide covers **Guardian 0.7.8**. Use the release notes, installation guide, and sample configuration for the version you install. Never copy notification addresses, credentials, or public-listing settings from an example into a production host.

Monitoring helps surface conditions to investigate. It does not prove node correctness, availability, or network service level.
