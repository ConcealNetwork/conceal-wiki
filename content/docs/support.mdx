title: Support
description: Use official Conceal support and project repositories without disclosing wallet recovery information.
---

Start with the official Conceal support route for user assistance. For a reproducible software defect, use the issue guidance in the relevant official repository after checking whether the report can be made without publishing sensitive information.

## What to include

Include the wallet or Core version, operating system or device type, the non-sensitive steps that led to the problem, and any non-sensitive error text. Link to the official release page you used if the problem concerns a download or update.

## What never to send

Never send recovery information, wallet passwords, exchange credentials, remote-access details, or API secrets to support. A legitimate responder can help interpret public documentation and troubleshoot non-sensitive symptoms without needing control of your funds or accounts.

## Verify the route

Open support links yourself from this page or the official Conceal site. Be cautious of lookalike domains, unsolicited direct messages, and anyone who demands payment or sensitive information to "unlock" a wallet.
