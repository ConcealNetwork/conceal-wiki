## Post-quantum research

The `pq-conceal` repository contains unaudited post-quantum cryptography research. It is experimental. It is not a consensus decision, production wallet, network upgrade, or replacement for released Conceal software.

Research code can change independently of released software. Before relying on an idea, inspect the repository and any current Core release material yourself. A proposal or experiment does not establish network support, compatibility, security properties, or a deployment timeline.

## Test research safely

- Keep research evaluation separate from ordinary wallet and node operations.
- Use the current [Releases & Verification](./releases-and-verification.mdx) guidance for released software.
- Treat a proposed consensus change as research until it appears in Core source and release notes.
