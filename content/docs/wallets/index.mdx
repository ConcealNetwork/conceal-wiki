Choose the wallet that matches your device and the amount of operational responsibility you are ready to take on. Before receiving funds, download only from a project-controlled source, verify the release information that is available, and finish your backup workflow.

## Compare the options

| Wallet | Best for | Platform | Operational responsibility |
| --- | --- | --- | --- |
| [Desktop](./desktop.mdx) | A graphical wallet with the full desktop workflow | Windows, macOS, Ubuntu, AppImage | Maintains local application and wallet data |
| [Core CLI](./core-cli.mdx) | Operators and command-line users | Windows, macOS, Ubuntu | Manages Core tools, files, node access and updates |
| [Web Wallet](./web.mdx) | Browser access without installing a desktop application | Modern browser | Protects the browser profile, extensions, device and recovery backup |
| [Android](./android.mdx) | A wallet on a supported Android device | Android | Verifies the APK and protects the device and recovery backup |
| [Next Wallet](./next-wallet.mdx) | Testing the next browser-wallet implementation | Modern browser | Experimental and unaudited; isolate testing from important funds |
| [Paper wallet](./paper-wallet.mdx) | Preparing an offline receiving record | Offline workflow | Secures generation, printing, storage and later recovery |

After choosing, follow the complete journeys for [installation](./install.mdx), [creation or recovery](./create-or-restore.mdx), [sending and receiving](./send-and-receive.mdx), and [updates or device moves](./update-and-move.mdx).

## Before a wallet change

1. Record and protect the recovery information produced by your existing wallet, without sending it to another person or service.
2. Confirm you can locate that backup before upgrading, reinstalling, clearing browser data, or changing devices.
3. Download the intended asset from its official repository release page.
4. Compare any published checksum or signature with the downloaded file using a trusted local verification tool.
5. Start with a small test transfer when moving to a new wallet or address workflow.

For recovery and device-change guidance, read [Backup & Security](../backup-and-security.mdx).
