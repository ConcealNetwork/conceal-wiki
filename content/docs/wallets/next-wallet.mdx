description: Review the risks before testing the experimental Conceal Next Wallet.
---

Next Wallet is experimental and unaudited. Do not use it as a replacement for an established wallet or move funds into it because someone describes it as ready.

## Evaluate before use

Read the repository, release information, and security policy yourself. Confirm the maintenance status, understand the recovery workflow, and assume that experimental software can change or fail in ways that production software should not.

If you choose to evaluate it, isolate that activity from funds you cannot afford to risk and retain a verified backup before any wallet or device change. Report security concerns through the repository's documented security process rather than posting sensitive details publicly.
