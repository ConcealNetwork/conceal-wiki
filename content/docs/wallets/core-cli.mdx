Core CLI is for operators and advanced users who are comfortable managing command-line software, local files, and updates. This guide covers Core 6.7.5. Check the releases page before installing because a newer version may be available.

## Before running Core tools

1. Obtain the appropriate package from the official Core release page.
2. Review the release notes and verify any published checksum or signature before use.
3. Decide where wallet recovery material and local data will be protected before creating or importing a wallet.
4. Keep a separate backup before changing versions, data locations, or machines.

## Operational boundary

CLI tools expose more settings than a graphical wallet. Follow the documentation for the release you installed. Keep RPC interfaces private unless you have designed access controls for them. Never paste recovery material into tickets, chats, or commands copied from strangers.

For node setup, use the [Run a Node](../run-a-node.mdx) guide and the Core repository.
