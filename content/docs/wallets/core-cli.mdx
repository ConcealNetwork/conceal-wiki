title: Core CLI Wallet

Core CLI is for operators and advanced users who are comfortable managing command-line software, local files, and updates. This guide covers Core 6.7.6. Check the releases page before installing because a newer version may be available.

## Before running Core tools

1. On Ubuntu, follow the PPA steps in [Run a Node](../run-a-node.mdx). For Windows, macOS, or an Ubuntu archive, obtain the file from the official Core release page.
2. Review the release notes. For a GitHub Release archive, verify any published checksum or signature before use.
3. Decide where wallet recovery material and local data will be protected before creating or importing a wallet.
4. Keep a separate backup before changing versions, data locations, or machines.

## Start the wallet

List the options for this install:

```bash
conceal-wallet --help
```

Open a wallet file:

```bash
conceal-wallet --wallet-file ~/.conceal/mywallet.wallet
```

Create a wallet file:

```bash
conceal-wallet --generate-new-wallet ~/.conceal/mywallet.wallet
```

The wallet connects to a daemon at `localhost` port `16000`. Use `--daemon-address`, `--daemon-host`, or `--daemon-port` when the daemon listens elsewhere. For a test network, pass `--testnet` to both the wallet and the daemon. Leave `--password` off the command line so the password is not stored in shell history.

## Operational boundary

CLI tools expose more settings than a graphical wallet. Follow the documentation for the release you installed. Keep RPC interfaces private unless you have designed access controls for them. Never paste recovery material into tickets, chats, or commands copied from strangers.

For node setup, use the [Run a Node](../run-a-node.mdx) guide and the Core repository.
