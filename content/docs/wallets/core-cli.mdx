Core CLI is suited to operators and advanced users who can manage command-line software, local files, and updates carefully. The verified migration snapshot is **Core 6.7.5**. It is a dated snapshot, not a substitute for reviewing the current official release page.

## Before running Core tools

1. Obtain the appropriate package from the official Core release page.
2. Review the release notes and verify any published checksum or signature before use.
3. Decide where wallet recovery material and local data will be protected before creating or importing a wallet.
4. Keep a separate backup before changing versions, data locations, or machines.

## Operational boundary

CLI tools can expose more configuration surface than a graphical wallet. Follow the repository documentation for the release you installed, keep RPC interfaces private unless you have a separately designed access control plan, and do not paste recovery material into tickets, chats, or commands copied from strangers.

For node-specific guidance, use the Core repository rather than an old forum or legacy-wiki command sequence.
