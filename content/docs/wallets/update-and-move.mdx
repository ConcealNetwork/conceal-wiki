---
title: Update or Move a Wallet
description: Update Conceal wallet software or move to a new device while keeping a recoverable previous state.
---

An update changes software. A device move also changes the environment holding wallet data. Prepare for recovery before doing either.

## Before an update

1. Record the installed wallet version and operating system.
2. Complete the wallet's supported backup or export process and confirm that you can locate the result.
3. Protect recovery information offline and separately from the device.
4. Read the new release notes for migration, compatibility or rescan requirements.
5. Verify the new download using [Install a Wallet](./install.mdx).
6. Keep the previous application and wallet data available until the updated wallet has synchronized and displayed the expected address and history.

Do not overwrite the only wallet file or clear browser data as part of routine troubleshooting.

## Move to a new device

1. Install a verified wallet on the new device without removing the old installation.
2. Restore using the supported recovery method described in [Create or Restore a Wallet](./create-or-restore.mdx).
3. Let the new wallet synchronize completely.
4. Compare its receiving address and transaction history with the old wallet.
5. Receive and send a small test amount when practical.
6. Only after recovery has been proven should you decide whether to remove wallet data from the old device.

Deleting an application does not reliably erase every backup, export, browser profile, temporary file or storage copy. Follow the old device's documented secure-erasure process if it will leave your control.

## Browser wallet moves

Browser data does not automatically follow you to another browser, profile or device. Export or record the wallet's supported recovery information before clearing site data, resetting a profile or replacing the device. Test the restore independently before removing the original.
