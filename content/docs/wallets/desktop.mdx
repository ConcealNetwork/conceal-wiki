The Desktop wallet is the graphical option for users who prefer a local application. The verified snapshot for this migration is **Desktop 6.7.8**. Treat that as a dated reference: use the official releases page to confirm the asset and release notes before installing.

## Safe installation path

1. Visit the official Desktop release page directly, rather than following a download link from a message.
2. Select the asset that matches your operating system and read its release notes.
3. If the release publishes a checksum or signature, verify the downloaded file before opening it.
4. Create or restore a wallet only after you have planned where its recovery material will be kept privately and offline.
5. Keep the installed application and operating system current through their documented update paths.

## Upgrades and recovery

Back up before an upgrade, device migration, or reinstall. Do not treat the application folder as a backup. If a change goes wrong, stop and use the wallet's documented recovery process with your own protected recovery material; a support responder should never need it.
