## Verify an APK before installation

1. Start at the official repository release page, then select the intended Android asset.
2. Read the release notes and compare its version and published integrity information with the downloaded APK.
3. If a checksum or signature is published, verify it locally before installation.
4. Confirm that the application package and its source match the official project, rather than trusting a re-upload, chat attachment, or ad.
5. Complete a private recovery backup before moving funds or replacing a device.

Android platform protections and installation prompts can differ by device and version. Keep the device updated, lock it appropriately, and do not disable security protections merely to install a wallet from an unverified source.
