CN-GPU mining participates in Conceal's proof-of-work network. Treat the Core source as the implementation reference for the current algorithm and network rules. Mining has hardware, electricity, software, pool, network, and market risk; this page does not estimate an outcome or recommend a miner, pool, or market.

## Before connecting hardware

1. Read the current [Core consensus configuration](https://github.com/ConcealNetwork/conceal-core/blob/master/src/CryptoNoteConfig.h) and [Core releases](https://github.com/ConcealNetwork/conceal-core/releases) before choosing software or updating a host.
2. Obtain mining software only from a source you independently trust, then verify its publisher, release notes, and any available checksum or signature. This documentation does not endorse third-party miners.
3. Use a wallet address that you control and verify it carefully before starting work. Keep recovery material out of mining hosts, scripts, tickets, and chat.
4. Check the [live Conceal explorer](https://explorer.conceal.network/) for current network and pool-directory information immediately before acting. The directory is live data, not a fixed list in this guide.

## Operational boundaries

Do not copy a configuration merely because it worked for someone else. Confirm the selected software, address, and network settings in your own environment. Keep mining hosts patched, restrict administrative access, and inspect logs locally for unexpected processes or configuration changes.

Pool availability and terms can change without notice. Assess a pool independently at the time you use it; this guide intentionally does not publish a pool comparison or standing performance figures.
