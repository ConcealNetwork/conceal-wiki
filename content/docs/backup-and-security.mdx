Recovery planning comes before a wallet upgrade, a browser reset, a reinstall, or a new device. A wallet application, device, or downloaded file is not by itself a backup.

## Backup before change

1. Use the wallet's documented backup or recovery flow while you still have normal access.
2. Keep the resulting recovery information private and offline, separate from the device where practical.
3. Confirm you can find the backup before changing software, clearing data, or moving devices.
4. Record which wallet and version created it, without recording sensitive material in a ticket, chat, or cloud note.
5. Test a recovery workflow with a small amount when the wallet documentation supports it.

## Verify downloads

Use project-controlled release pages. Match the asset to its release notes, then compare any published checksum or signature with your downloaded file using a trusted local tool. A matching filename alone does not establish that a download is authentic.

## If something goes wrong

Pause before deleting data or following a copied command sequence. Preserve the information you still have, review the installed wallet's current documentation, and contact official support without providing recovery material. A responder can help explain a process but should not ask for the information that controls your funds.
